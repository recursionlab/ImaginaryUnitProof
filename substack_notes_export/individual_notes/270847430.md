Corpus Percolation Scanner: Minimal Viable Implementation

Build a standalone claim percolation scanner that analyzes a corpus of 50+ sources to identify global sections (Stabilons) and fault lines (Glitchons) using the existing spectral theory framework. The tool will extract claims from each source, cluster similar claims across sources, compute coverage and cross-cluster metrics, and classify each claim cluster.

Corpus Percolation Scanner: Minimal Viable Implementation

Overview

Build a command-line tool that scans a corpus of source files to identify:





Global Sections: Claims that appear across multiple independent source types (high coverage + cross-cluster)



Glitchons: Claims with conflicts or high contradiction density



False Percolation: Claims that only appear within a single source cluster

This is the minimal viable version of the platform's corpus analysis capability, using the existing OpenRouter integration and spectral metrics.

Architecture

Components





Source Loader (source-loader.ts)





Load files from a directory (markdown, txt, pdf text)



Parse metadata to determine source type (RCOS, mathematics, prior, external)



Return map: sourceId → { text, type, metadata }



Claim Extractor (claim-extractor.ts)





Use LLM (OpenRouter) to extract falsifiable claims from each source



Prompt returns structured JSON: { claim, type, dependsOn }



Cache results to avoid re-extraction



Claim Normalizer (claim-normalizer.ts)





Semantic deduplication: identify when different phrasings refer to the same claim



Use embedding similarity or LLM judgment



Assign cluster IDs



Cluster Builder (cluster-builder.ts)





Group claims by normalized identity



Compute cluster statistics: coverage, source types, conflict detection



Conflict Detector (conflict-detector.ts)





For claims in the same cluster (same underlying claim), check if any pair conflicts



Use LLM to determine agreement/conflict/independent/supports



Classifier (classifier.ts)





Apply thresholds:





Global Section: coverage > 0.3 AND isCrossCluster = true



Glitchon: has conflicts OR (coverage > 0.1 AND isCrossCluster = false)



False Percolation: coverage < 0.05



Local: otherwise



Compute composite score for ranking



Main Scanner (corpus-scanner.ts)





Orchestrate the pipeline



Output JSON/HTML report

Technical Approach

Input Format

Sources are files in a directory with optional metadata in frontmatter or filename:

Copy

sources/
  rcos-001.md          # type inferred from path prefix
  math-paper-42.txt
  prior-session-3.mdexternal-wiki.md

Or a manifest JSON:

jsonCopy

{
  "sources": [
    { "id": "rcos-001", "path": "sources/rcos-001.md", "type": "rcos" },
    { "id": "math-42", "path": "sources/math-paper-42.txt", "type": "mathematics" }
  ]
}


Claim Extraction Prompt

Copy

Extract all falsifiable mathematical or structural claims from this text.
For each claim output:
- claim: one sentence statement (clear, precise)
- type: derived | asserted | postulated
- depends_on: list of other claims it requires (by their claim text)

Return JSON array only.


Normalization Strategy

Two-phase approach:





Light normalization: lowercase, strip punctuation, remove stop words



Semantic clustering:





Option A: Use LLM to judge if two claims are "the same claim"



Option B: Compute embeddings (via OpenRouter) and cluster by cosine similarity > 0.85



For MVP: use simple string similarity (Jaccard on tokens) with threshold 0.7

Conflict Detection

For each cluster with >1 claim:





Compare every pair using LLM: Copy 

Claim A: {text}
Claim B: {text}

Do these claims:
1. agree (same content, different phrasing)
2. conflict (logically incompatible)
3. independent (unrelated)
4. one-supports-other (A implies B or B implies A)

Return JSON: {"relation": "agree|conflict|independent|supports", "note": "..."}




If any pair returns "conflict", mark cluster as having conflicts

Cross-Cluster Determination

A cluster is "cross-cluster" if its sources span at least 2 different source types.

Classification Logic

typescriptCopy

function classifyCluster(cluster: ClaimCluster): ClaimCluster['status'] {
  if (cluster.coverage > 0.3 && cluster.isCrossCluster) {
    return 'GLOBAL_SECTION';
  }
  if (cluster.conflicts.length > 0) {
    return 'GLITCHON';
  }
  if (cluster.coverage < 0.05) {
    return 'LOCAL';
  }
  if (cluster.coverage > 0.1 && !cluster.isCrossCluster) {
    return 'FALSE_PERCULATION';
  }
  return 'LOCAL';
}


Scoring for Ranking

typescriptCopy

score = coverage * (isCrossCluster ? 1.5 : 1.0) * (hasConflicts ? 0.5 : 1.0)


Global sections ranked by score descending.
