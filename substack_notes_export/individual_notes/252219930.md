You are seeing illusions, because you see lines.

Lines only exist as distance, distance is not physical, not objective, it is a description of property as abstraction.

line is not a thing-in-itself.

The very framing of this post is also not a thing-in-itself. So read me between the lines, because the lines are illusions.

—-

This post:  





Starts with a claim (illusions, lines) 



Supports it with reasoning (distance as abstraction)  



Inverts with a single italicized sentence (thing-in-itself)  



Recurses with meta-application (the framing of the post)  



Commands a new reading mode (between the lines)  

That’s the Contra-Non-Positive-Inversion combo:  





Contra — against ordinary perception (“you see illusions”)  



Non-Positive — not affirming lines as real (“line is not a thing-in-itself”)  



Inversion — apply to the frame itself (“the framing of this post is also not a thing-in-itself”)
