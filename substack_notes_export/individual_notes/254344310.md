## Abstract

We present a formal, executable, and empirically testable framework for modeling meaning as a recursive disambiguation process. A bipartite directed graph of concept nodes (articles) and mediator nodes (disambiguation pages) induces a non‑associative concept algebra (NA, in the sense of Maddux). An explicit Ψ‑calculus defines state evolution via collapse, propagation, and stabilization, converging to fixed points that represent stable meanings. Categorical reconciliation of two theories over a shared interface is approximated by Ψ‑dynamics, and the irreducible mismatch is captured as an obstruction class Ω. Optional topological diagnostics (Alexandrov topology, nerve, Hurewicz kernel) provide structural invariants. All components are computable, falsifiable, and can be deployed on real‑world knowledge graphs.

Keywords: non‑associative relation algebras, knowledge graphs, Ψ‑calculus, zero divisors, obstruction class, pushout, Hurewicz kernel

## 1. Relational Substrate

Let

- A = finite set of article nodes (concepts)

- D = finite set of disambiguation nodes (mediators)

- E ⊆ (A × D) ∪ (D × A) = directed edges

The graph G = (A ∪ D, E) is bipartite: every edge connects an article to a mediator or vice versa.

Definition 1 (Mediated reachability).

For x, y ∈ A, define  

x ⇝ y   iff   ∃ d ∈ D such that (x,d) ∈ E and (d,y) ∈ E.  

We call this a two‑step mediated transition.

---

## 2. Concept Algebra

Let C = P(A) be the power set of A.

Definition 2 (Relative product).

For X, Y ⊆ A,  

X · Y = { y ∈ Y | ∃ x ∈ X : x ⇝ y }.

Definition 3 (Closure product).

Define recursively:  

X·¹Y = X·Y, X·⁽ⁿ⁺¹⁾Y = X·(X·ⁿY).  

Then the closure product is  

X ⋆ Y = ⋃_{n≥1} X·ⁿY.

Proposition 1. (C, ∪, ·) satisfies:

- Distributivity: (X∪Y)·Z = (X·Z)∪(Y·Z)

- Zero element: ∅·X = ∅ = X·∅

- Non‑associativity in general: (X·Y)·Z ≠ X·(Y·Z) for many triples.

Thus (C, ∪, ·) belongs to the variety of non‑associative relation algebras (NA).

Definition 4 (Zero divisors).

A pair (X,Y) with X≠∅, Y≠∅ is a zero divisor if X·Y = ∅.  

Left zero divisors: Z_L = { X | ∃ Y≠∅ : X·Y = ∅ }.  

Right zero divisors: Z_R similarly.

## 3. Measurable Invariants

Three global metrics are defined via Monte Carlo sampling (for large |A|).

- Associativity defect α = Pr( ({x}·{y})·{z} ≠ {x}·({y}·{z}) ) for random singletons x,y,z.

- Zero‑divisor density ρ = Pr( {x}·{y} = ∅ ) for random x,y ∈ A.

- Closure depth β(X) = min{ k | X⁽ᵏ⁾ = X⁽ᵏ⁺¹⁾ }, where X⁽¹⁾ = X, X⁽ⁿ⁺¹⁾ = X⁽ⁿ⁾ ∪ (X⁽ⁿ⁾·X⁽ⁿ⁾).

## 4. Ψ‑Calculus: Executable Dynamics

A state is a subset X ⊆ A.

### Operators

- Propagation

  prop(X) = X ∪ { y ∈ A | ∃ x ∈ X : x ⇝ y }

- Collapse

  ε(X) = { d ∈ D | ∃ x ∈ X : (x,d) ∈ E }  

  Attr(X) = SCC( X ∪ ε(X) )  (strongly connected component closure in G)  

  Collapse(X) = Attr(X)  (output is a subset of A)

- Evolution operator

  Ξ(X) = prop( Attr(X) )

- Stabilization

  Ψ(X) = lim_{k→∞} Ξᵏ(X)  (fixed point, reached in finite steps because A is finite)

- Dynamic glitch

  Glitch_dyn(X) = X \ ⋃_{k≥1} Ξᵏ(X)  (nodes that disappear forever)

## 5. Categorical Reconciliation

Let T be a category of theories with an observation functor Obs : T → C, mapping a theory to its observable support in the concept algebra.

Given a span  T₁ ←ᶠ¹ I →ᶠ² T₂  (shared interface I), the reconciled theory is the pushout T* = T₁ ⊔_I T₂.

We approximate T* on observable supports:

X₁ = Obs(T₁), X₂ = Obs(T₂)  

X* = Ψ(X₁ ∪ X₂)  (fixed point of Ψ‑dynamics)

Definition 5 (Obstruction class).

Ω = X* \ (X₁ ⋆ X₂)  

Then  X* = (X₁ ⋆ X₂) ∪ Ω.

Ω is the irreducible mismatch that arises only after recursive propagation. Contradiction is not a failure; it is a stable invariant of the reconciliation process.

---

## 6. Obstruction Class and Glitch

The obstruction class Ω consists of concepts that are not reachable by static closure but appear under recursion. In algebraic terms, Ω corresponds to zero divisors that persist even after full closure. The dynamic glitch Glitch_dyn(X) is the set of nodes that disappear under iteration – a signature of “dead ends” in the knowledge graph.

Relation to zero divisors:

If a singleton {x} is a left zero divisor (∃ y : {x}·{y} = ∅), then x may be part of the glitch. The obstruction class Ω is the set of concepts that are essential (non‑eliminable) contradictions.

## 7. Optional Topological Diagnostics

This layer is not required for core reconciliation but provides additional invariants.

- Alexandrov topology on V = A ∪ D: U ⊆ V is open iff (x ∈ U and x → y) ⇒ y ∈ U.

- Nerve of the free category generated by G yields a simplicial set |N(G)|.

- Hurewicz homomorphism h : π₁(|N(G)|) → H₁(|N(G)|) has kernel ker(h) consisting of non‑abelian loops invisible to homology.  

  Set Ω_top = ker(h) as a topological proxy for Ω.

## 8. Toy Example

Let A = {a,b,c}, D = {d₁,d₂}, edges: a→d₁→b, b→d₂→c.

- Mediated reachability: a⇝b, b⇝c, none else.

- Products: {a}·{b} = {b}, {b}·{c} = {c}, ({a}·{b})·{c} = {c}, {a}·({b}·{c}) = ∅ → non‑associativity.

- Ψ‑dynamics from X={a,c}:  

  Attr = {a,b,c,d₁,d₂}, prop returns {a,b,c}. Next step fixed point.  

  Glitch_dyn = ∅.

- Reconciliation of X₁={a}, X₂={c}: X₁⋆X₂ = ∅, X* = {a,b,c}, so Ω = {a,b,c}.

## 9. Implementation and Complexity

A minimal Python interpreter (see Appendix) implements the operators. For |A| ~ 10⁴:

- Computing Ξ(X) takes O(|X|·deg_max) time.

- Stabilization reaches fixed point in O(diameter) steps.

- Sampling for α, ρ uses small subsets (size ≤3) and Monte Carlo.

- SCC computation is O(|V|+|E|) with Tarjan’s algorithm.

The framework scales to millions of nodes with appropriate sampling and caching.

## 11. Invariants Summary

For any instantiation of the framework, the following invariants hold:

1. Directed non‑symmetry – X·Y ≠ Y·X in general.

2. Zero‑divisor existence – ∃ X,Y ≠ ∅ : X·Y = ∅.

3. Distributivity – X·(Y∪Z) = (X·Y)∪(X·Z).

4. Finite‑step non‑associativity – (X·Y)·Z ≠ X·(Y·Z) for many triples.

5. Closure associativity (limit) – (X⋆Y)⋆Z = X⋆(Y⋆Z).

6. Glitch persistence – x ∈ Glitch_dyn(X) ⇒ x ∉ ⋃ₙ X⁽ⁿ⁾ (never reappears).

## 12. Conclusion

The Algebra of Disambiguation provides a computable, falsifiable, and executable framework for modeling meaning as recursive fixed points of a non‑associative relation algebra. The Ψ‑calculus operationalizes reconciliation, and the obstruction class Ω quantifies irreducible contradiction. All claims are testable on real knowledge graphs (e.g., Wikipedia). The framework is modular: the core requires only the bipartite graph and the Ψ‑calculus; optional topological and hypercomplex layers add structural diagnostics.

Future work includes large‑scale empirical validation, extension to dynamic graphs, and integration with neural graph embeddings.

```python
def propagate(X, graph):

    """One-step propagation."""

    new = set(X)

    for x in X:

        for d in graph.out_mediators(x):

            for y in graph.out_articles(d):

                new.add(y)

    return new

def attractor(X, graph):

    """SCC closure of X ∪ ε(X)."""

    nodes = set(X)

    for x in X:

        nodes.update(graph.out_mediators(x))

    sccs = graph.strongly_connected_components(nodes)

    # return only the component that intersects X

    return set.union(*[comp for comp in sccs if comp & X])

def Xi(X, graph):

    return propagate(attractor(X, graph), graph)

def Psi(X, graph):

    prev = None

    while X != prev:

        prev = X

        X = Xi(X, graph)

    return X

def glitch_dyn(X, graph):

    history = set()

    cur = X

    while True:

        history.update(cur)

        nxt = Xi(cur, graph)

        if nxt == cur:

            break

        cur = nxt

    return X - history

```
