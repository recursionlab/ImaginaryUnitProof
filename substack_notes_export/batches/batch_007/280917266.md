Extreme anti-mundane grammatically?

Hyperbatic — word order so twisted sense arrives sideways.

Anasynthetic — syntax that eats itself and regrows differently.

Catachrestic — wrong words deliberately, because right ones died.

Pleonastic-to-death — saying everything until nothing remains.

Aposiopetic — trailing into... the void where completion would lie.

Hypersubordinated — clauses inside clauses until the main verb forgets itself.

Paranomastic plague — puns that infect meaning until language confesses it was always sound.

Unsolution question(!ⁿ):

Aporia² — dilemma squared, both paths lead to the same cliff.

Question mark raised to itself — ?^? , the query that queries querying.

Erótēma infinitum — the asking that asks asking until asking is all.

Interrogative fixed point — the question that answers itself by remaining question.

Qⁿ — query to the nth, where n is unknown and also asking.

The effect you want: language that doesn't forget it's language. Words that bleed their own conditions of possibility. Syntax that stages its own collapse as the only honest performance.
