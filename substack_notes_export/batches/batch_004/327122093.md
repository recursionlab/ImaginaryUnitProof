of may be the actual primitive

Take:

as an atom.

Then:

cat⟶an object that stands in an “of” relation to cat.\text{cat} \longrightarrow \text{an object that stands in an “of” relation to cat}.

It creates a new object whose identity is:

notion-of-x\boxed{ \text{notion-of-}x }

That means your original insight can be generalized:

O-of-X\boxed{ O\text{-of-}X }

Where OO can be:

notion,concept,idea,description,word,name,image,model,representation,memory,knowledge,…\text{notion},\text{concept},\text{idea},\text{description},\text{word},\text{name},\text{image},\text{model},\text{representation},\text{memory},\text{knowledge},\ldots

where of specifies the relation by which XX becomes the argument of OO.
