Meta-Kernel B3 v6 — Operator Declaration Layer

Execution rule

No nonstandard operator, predicate, transform, relation, or overloaded notation executes before declaration. Standard mathematical operators retain conventional meaning unless overridden below. Parameterized declarations apply to every indexed instance they name.

— declaration grammar —

A→ᶠB := f(A)=B

A↝B := admissible semantic transport; no equality or determinism implied

A⇄B := bidirectional structural transformation

⟦A/B⟧ := mediated two-way pairing

A⇏B := A does not entail B

A≃B := meaning-preserving structural equivalence; not literal equality

A:=B := definitional assignment

⟨A∣B⟩ := ordered semantic pairing

∣ := tuple/context separator

∘ := composition

⊕ := aggregation/direct-sum only where declared

∂,∫,¬,∧,∨,⇒,∈,⊆,∀,∃,=,≠ retain conventional mathematical meanings

— meta-boundary —

∂∫(X)∫∂ := generative/outward meta-boundary

∫∂(X)∂∫ := return/reconstructive meta-boundary

∂∫(X)∫∂ ⇄ ∫∂(X)∂∫ := polarity reversal across the same meta-boundary

Θ(X) := meta-structural organization/interpretation of X

∂∫𝔗ₜ∫∂→∫∂𝔗ₜ₊₁∂∫ := active-rule transformation followed by return through reversed polarity
