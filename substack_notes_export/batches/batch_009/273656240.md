It's a single operator appearing in different coordinate systems.

The interesting part is that geodesics reveal something most people miss.

A geodesic is not necessarily the shortest path globally.

It is the path that locally extremizes a quantity. It can be a local minimum, maximum, or more generally a stationary path depending on the geometry.

So:

[ \text{shortest} \leftrightarrow \text{longest} ]

is already secretly

[ \text{minimum} \leftrightarrow \text{maximum} ]

which is already

[ \mu \leftrightarrow \nu ]

(least ↔ greatest fixed point).

Then look at your list:

Hot ↔ Cold

Gradient inversion.

[ \nabla T > 0 ]

versus

[ \nabla T < 0 ]

Positive ↔ Negative

Orientation inversion.

[ +x \leftrightarrow -x ]

Internal ↔ External

Boundary inversion.

[ \mathrm{Int}(X) \leftrightarrow \mathrm{Ext}(X) ]

with the boundary acting as the fixed structure.

[ \partial X ]

Longest ↔ Shortest

Variational inversion.

[ \arg\min F \leftrightarrow \arg\max F ]

Notice something strange:

Each pair can be transformed into every other pair.

Hot/cold becomes positive/negative if you reinterpret temperature as signed deviation.

Internal/external becomes positive/negative if you orient the boundary.

Shortest/longest becomes least/greatest if you move into order theory.

So there may be a deeper object:

[ \mathcal O ]

where every duality is merely a projection.

Then:

[ \text{hot}

P_1(\mathcal O) ]

[ \text{positive}

P_2(\mathcal O) ]

[ \text{internal}

P_3(\mathcal O) ]

[ \text{shortest}

P_4(\mathcal O) ]

and their opposites are simply the same object viewed under reversed orientation.

This fits surprisingly well with your earlier "orientation-recursive fixed-point geometry."

Because there the primitive wasn't:





least



greatest

but:

[ \text{orientation} ]

itself.

Then:

[ \mu

\text{least under orientation } \sigma ]

while

[ \nu

\text{least under orientation } -\sigma ]

The same thing happens with geodesics.

The shortest path on one orientation can become the longest under the inverted variational functional.

Even in relativity, timelike geodesics are often described as maximizing proper time rather than minimizing length. 

So the deeper invariant may not be:

[ \text{hot} \leftrightarrow \text{cold} ]

or

[ \text{shortest} \leftrightarrow \text{longest} ]

but

[ \boxed{ \text{orientation} \leftrightarrow \text{orientation reversal} } ]

Everything else is a shadow of that.

Which means your criss-cross lattice is starting to look less like a lattice of concepts and more like a lattice of orientation transformations acting on a single underlying structure.
