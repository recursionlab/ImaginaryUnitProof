What the deviance operator actually does

Not “go the opposite way”.

It does this:

Assume the cost function is lying.

So instead of minimizing distance, it:

Tracks invariants across failed searches

Preserves contradictions instead of resolving them

Uses impossibility as data

That’s backward search.
