1. TEMPORAL: Operations on time/sequence (retro-, pre-, post-, proto-)

2. SPATIAL: Operations on space/position (trans-, para-, supra-, infra-)

3. RELATIONAL: Operations on relations (meta-, anti-, co-, auto-)

4. SCALAR: Operations on scale/magnitude (hyper-, micro-, mega-, nano-)

5. NEGATION: Operations inverting/opposing (anti-, contra-, non-, de-)

6. PREPOSITIONAL: Operations on position (across-, through-, beyond-, beneath-)

7. STRUCTURAL: Operations on form (-genesis, -stasis, -cycle, -fusion)

COMPOSITION VALIDITY:

✓ Same category: Temporal ∘ Temporal → Temporal

✓ Cross-category: Relational ∘ Temporal → Relational

✗ Type clash: Scalar ∘ Structural → undefined (requires bridge)

DEPTH LIMITS:

- Depth 1: prefix(concept) - always valid

- Depth 2: prefix₁ ∘ prefix₂(concept) - check type compatibility

- Depth 3+: Rarely semantically coherent; flag for validation

§3. OPERATOR DISCOVERY PROTOCOL

═══════════════════════════════════════════════════════════

When encountering UNKNOWN operator/prefix:

STEP 1 - PATTERN RECOGNITION

- Identify linguistic form (prefix/suffix/compound)

- Detect semantic category (temporal/spatial/relational/etc.)

- Check composition context (what does it modify?)

STEP 2 - TYPE ASSIGNMENT

Assign to category:

[TEMPORAL | SPATIAL | RELATIONAL | SCALAR | NEGATION | PREPOSITIONAL | STRUCTURAL]

STEP 3 - COMPOSITION TEST

- Does it compose validly with known operators?

- What's its type signature: Input → Output?

- Are there type errors or constraints?

STEP 4 - PRECEDENT SCAN

- Does this exist in known frameworks? (philosophy/science/math)

- Is it derivative of existing operator?

- Is it novel compound?

STEP 5 - INTEGRATION DECISION

→ ADD if: Novel + compositionally sound + useful

→ DERIVE if: Compound of existing operators (log as macro)

→ REJECT if: Type-unsafe or semantically incoherent

STEP 6 - TAXONOMY UPDATE

Add to active operator library with:

- Symbol/notation

- Type category

- Composition rules

- Related operators

- Example usage
