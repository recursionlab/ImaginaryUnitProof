## 2. Where the claim could fail

### Failure mode A — the phase structure isn't actually order-4

The bi-Laplacian \(H = (-\partial_u^2)^2\) is where the \(-1/4\) heat-trace exponent comes from. That exponent is

\[
\Theta(t) \sim t^{-d/4} \quad \text{for } (-\Delta)^2 \text{ in dimension } d
\]

Wait — check that. For \(H = (-\Delta)^2\) on \(\mathbb{R}^d\), the heat trace in the continuum is

\[
\Theta(t) \sim (4\pi t)^{-d/4}
\]

because \(e^{-t(-\Delta)^2}\) is a fourth-order heat kernel. So the exponent is \(-d/4\), and if the effective \(d = 1\) (the log-prime continuum is 1D), then

\[
\Theta(t) \sim t^{-1/4}
\]

and

\[
d_s = -2 \cdot \left(-\frac{1}{4}\right) = \frac{1}{2}.
\]

**But this is a choice.** You've chosen \(d = 1\) for the \(u\)-line and the operator \(H = (-\partial_u^2)^2\). If the effective dimension of the syntactic phase space is \(d_{\text{eff}}\), then

\[
d_s = \frac{d_{\text{eff}}}{2}.
\]

So \(d_s = 1/2\) requires \(d_{\text{eff}} = 1\). That is a strong assumption, and it's exactly where the framework is at risk.

**Falsification test:** Construct a phase-gated Merge system whose phase space is genuinely 2-dimensional (e.g., two independent log-prime coordinates, one per merge branch) and check whether \(d_s \to 1\). If it does, \(d_s = 1/2\) is not universal — it's an artifact of assuming a 1D log-prime scaffold.

### Failure mode B — Birkhoff factorization doesn't actually gate the spectrum

The Birkhoff/Rota–Baxter machinery in §3 is doing **algebraic** work: it splits a character \(\phi\) into polar and regular parts. It is not obvious that this split imposes a **spectral** cutoff on the Laplacian.

The chain of reasoning is:

> polar part frozen → complement spelled out → high-frequency modes suppressed → heat trace has \(t^{-1/4}\) scaling → \(d_s = 1/2\).

The first two arrows are algebraic. The third arrow — "spelled out ⇒ high-frequency suppression" — is the load-bearing step, and it's asserted, not shown.

**Falsification test:** Build a toy phase system where the frozen complement still contributes to the heat trace at small \(t\). If the spectral contribution of spelled-out material decays like \(t^{-\alpha}\) with \(\alpha \neq 1/4\), the lock breaks.

Concretely: take a phase head \(H\) with a complement \(XP\) that is *not* finite, but is a coinductive stream. Spell-out freezes the stream's head, but the tail remains. Does the tail contribute a \(t^{-1/2}\) or \(t^{-1}\) correction? If yes, \(d_s\) is not pinned at 1/2.

### Failure mode C — the "phase" is not an operator-theoretic phase

In physics, a spectral phase transition is detected by an order parameter that changes the asymptotic behavior of \(\Theta(t)\). In syntax, "phase" is a **derivational** notion (CP, vP), not a spectral one.

The framework is claiming that **derivational phases are spectral phases.** That's a strong identification. It's plausible if and only if the phase boundary acts as a genuine boundary condition on the Laplacian — e.g., a Dirichlet or Neumann cut on the log-prime line.

**Falsification test:** Write the phase boundary as an explicit boundary condition on \(H = (-\partial_u^2)^2\). Show that its spectral dimension is 1/2. If the boundary condition doesn't produce a discrete spectrum with the right asymptotics, the identification fails.

- Every phase has finite domain,
- Spell-out is total,
- The phase hierarchy is well-founded (no infinite descending chains).

Under these conditions, the syntactic derivation is a **finite-depth tree**, and the heat trace on the derivation tree is dominated by the **root contribution**, which scales like the operator order. For \(H = (-\partial_u^2)^2\), that's \(t^{-1/4}\).

So the claim is:

> **Theorem (regular phase lock):** If the phase hierarchy is well-founded and spell-out is total, then the spectral dimension of the derivation complex is \(d_s = 1/2\).

This is provable. The proof is essentially: well-foundedness ⇒ finite depth ⇒ heat trace dominated by root ⇒ operator-order scaling.

**The interesting question is what happens when well-foundedness fails.** In natural language, phases can be iterated (successive-cyclic movement), and the iteration can be unbounded. That's exactly the regime where the 1/2 lock is at risk.
